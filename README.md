# Obstacle Roll

An **infinite-runner style game** featuring **physics-based rolling movement** and **procedurally generated obstacles**.  
The player navigates an endless course by **sliding left and right** to avoid obstacles while maintaining momentum.

**Play in Browser**:  
https://muharabi.github.io/Obstacle-Roll/

**Download (Windows / macOS / Linux)**:  
Available through the **Personal Projects** section of my profile website:  
https://muharabi.github.io/Website-Project/

---

## Features

- Infinite-runner style gameplay
- Physics-based rolling mechanics
- Left and right sliding controls (no jumping)
- Procedurally generated obstacles
- Sound effects and background audio
- Playable directly in the browser
- Downloadable builds for Windows, macOS, and Linux

---

## Technologies Used

- **JavaScript**
- **HTML5**
- **CSS3**
- **Web Audio API**
